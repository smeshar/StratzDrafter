# Stratz Custom Dota 2 Drafter

Кастомный драфтер для Dota 2 на базе **STRATZ GraphQL API** с упором на **контрпики (70%)**, гибкую мету (поддержка офф-мета пиков вроде керри Фуриона) и подсказки для **всей команды (всех 5 позиций)**.

---

## Быстрый запуск и Установка

### Вариант 1 (Для друзей — Автоматический установщик):
Просто запустите файл **[setup.bat](file:///d:/VSCodeProjects/StratzDrafter/setup.bat)**:
1. Проверит наличие Python на компьютере.
2. Спросит ваш персональный токен **STRATZ API** (если токена нет, можно нажать Enter и играть на оффлайн-кэше).
3. Автоматически установит все библиотеки и зависимости.
4. Создаст готовый ярлык **«StratzDrafter»** прямо на **Рабочем столе**.

### Вариант 2 (Обычный запуск):
Запустите файл **[run.bat](file:///d:/VSCodeProjects/StratzDrafter/run.bat)**. Сервер поднимется и сам откроет браузер:  
**http://localhost:5000**

### Вариант 3 (Через консоль):
```bash
python app.py
```
Откройте в браузере: `http://localhost:5000`

## Почему этот драфтер лучше стандартного ROSH от Stratz?

1. **Приоритет контрпиков (по умолчанию 70%)**:
   - На низких и средних рангах (Herald, Guardian, Crusader, Archon) игра выигрывается правильным контрпиком конкретных вражеских героев, а не идеальной синергией про-сцены.
   - Вы можете на лету двигать слайдеры:
     - **Контрпики**: 70% (настраивается от 0% до 100%)
     - **Синергия**: 20%
     - **Мета**: 10%
2. **Свобода от узкой меты (Керри Фурион и другие пики)**:
   - ROSH штрафует героев, если они «не в мете» на своей роли.
   - Наш драфтер учитывает реальные преимущества: если герой отлично контрит вражеский драфт, он будет показан с плашкой `[ОФФ-МЕТА]` и высоким рейтингом.
   - Есть переключатель: «*Разрешить офф-мета*».
3. **Драфтер для всей команды (все 5 позиций одновременно)**:
   - Вкладка **«Сетка всей команды»** выводит 5 колонок:
     - **Поз 1 (Керри)**
     - **Поз 2 (Мид)**
     - **Поз 3 (Оффлейн)**
     - **Поз 4 (Семи-саппорт)**
     - **Поз 5 (Фулл-саппорт)**
   - Вы сразу видите, что посоветовать каждому из друзей в дискорде!
   - Кнопка **«В Discord»** копирует готовый форматированный текст со списком лучших пиков для всех ролей.
4. **Умный поиск по русскому сленгу Dota 2**:
   - Поиск мгновенно находит героев по русским прозвищам: `фура`, `фурион`, `ам`, `магина`, `папич`, `вк`, `пудж`, `гуля`, `сф`, `тракса`, `бара`, `коза`, `конь`, `дед` и др.
5. **Мгновенная работа (0 мс задержки)**:
   - Полная матрица матчапов Stratz кэшируется в локальный файл `data/matchups_cache.json`.
   - Рекомендации рассчитываются за 20 миллисекунд прямо на вашем ПК.

## Структура проекта

- [app.py](file:///d:/VSCodeProjects/StratzDrafter/app.py) — Flask веб-сервер и API endpoints (`/api/team_matrix`, `/api/recommend`, `/api/heroes`).
- [stratz_client.py](file:///d:/VSCodeProjects/StratzDrafter/stratz_client.py) — Клиент GraphQL Stratz API, расчет матчапов, винрейтов и локальное кэширование.
- [aliases.py](file:///d:/VSCodeProjects/StratzDrafter/aliases.py) — База русских прозвищ и сленга героев Dota 2 для удобного поиска.
- [templates/index.html](file:///d:/VSCodeProjects/StratzDrafter/templates/index.html) — Минималистичный интерфейс в стиле Dota 2.
- [static/css/style.css](file:///d:/VSCodeProjects/StratzDrafter/static/css/style.css) — Тёмный дизайн с эффектом матового стекла (Glassmorphism).
- [static/js/app.js](file:///d:/VSCodeProjects/StratzDrafter/static/js/app.js) — Логика выбора слотов, переключения ролей, отправки в бан и копирования в буфер.
- [run.bat](file:///d:/VSCodeProjects/StratzDrafter/run.bat) — Скрипт быстрого запуска для Windows.
- [run_tests.bat](file:///d:/VSCodeProjects/StratzDrafter/run_tests.bat) — Скрипт запуска автоматических тестов (Unit, API, E2E).
- [.env](file:///d:/VSCodeProjects/StratzDrafter/.env) — Токен `STRATZ_API`.
- `data/` — Локальный кэш (создается автоматически):
  - `heroes_cache.json` — Список героев Dota 2.
  - `stats_cache.json` — Статистика по 5 позициям.
  - `matchups_cache.json` — Полная матрица контрпиков и синергий.
- `tests/` — Набор из 59 автоматических тестов (pytest + Playwright).

## 🌐 Хостинг на Ubuntu (VPS)

Для развертывания проекта на сервере Ubuntu:
1. Загрузите файлы проекта на сервер (через Git, SCP или SFTP).
2. Запустите скрипт автоматического развертывания:
   ```bash
   bash deploy.sh
   ```
Скрипт сам установит Python, Nginx, создаст службу systemd для круглосуточной работы 24/7 и настроит проксирование на порт 80.
