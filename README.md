# Настройка рекомендаций
![alt text](image-1.png)

Главная особенность программного обеспечения от других драфтеров - гибкая настройка рекомендаций.
Если вам не так сильно важна синергия с тиммейтами (например, на лоу рангах), то вы можете просто уменьшить ее значимость как фактора отбора.
