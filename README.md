# Stratz Custom Dota 2 Drafter

Кастомный советник драфта для Dota 2 на базе **STRATZ GraphQL API** с упором на **контрпики (70%)**, гибкую офф-мету и сетку для **всех 5 позиций одновременно**.

🌐 **Онлайн-сайт:** [https://programnoe-obespechenie.duckdns.org/](https://programnoe-obespechenie.duckdns.org/)

---

## StratzDrafter против других драфтеров

| Возможность | Другие драфтеры (Stratz ROSH, Dotabuff) | **StratzDrafter** |
| :--- | :---: | :---: |
| **Настройка влияния (Контрпики / Синергия / Мета)** | ❌ Жестко зашито в алгоритм | ⚙️ **Слайдеры от 0% до 100% (70% контрпики по дефолту)** |
| **Офф-мета пики (керри Фурион, мид Пудж)** | ❌ Штрафуются и скрываются | ✅ **Поддерживаются (переключатель «Офф-мета»)** |
| **Драфт для всей пати (все роли)** | ❌ Только 1 текущий слот | 👥 **Все 5 позиций одновременно в одной сетке** |
| **Поиск по русскому сленгу** | ❌ Только официальные названия | 🔍 **«фура», «ам», «пудж», «папич», «гуля» и др.** |
| **Быстрый выбор с клавиатуры** | ❌ Только клики по модалкам | ⌨️ **Ввод на позиции + компактный popover под слотом** |
| **Скорость отклика** | ⏳ Сетевые задержки при кликах | ⚡ **0 мс (локальный кэш 127×127 героев)** |

## Быстрый запуск

### Вариант 1. Запуск на компьютере (Windows)
* Для друзей (установщик на рабочий стол): запустите **[setup.bat](file:///d:/VSCodeProjects/StratzDrafter/setup.bat)**
* Обычный запуск: запустите **[run.bat](file:///d:/VSCodeProjects/StratzDrafter/run.bat)** (откроет `http://localhost:5000`)

### Вариант 2. Развертывание на сервере (Ubuntu VPS)
```bash
git clone https://github.com/smeshar/StratzDrafter.git
cd StratzDrafter
bash deploy.sh
```
*Скрипт сам настроит swap, venv, systemd-сервис и Nginx.*

Обновление сервера одной командой:
```bash
bash update.sh
```

## Архитектура проекта

```
StratzDrafter/
├── app.py                  # Flask веб-сервер и REST API
├── stratz_client.py        # Клиент Stratz API, расчет винрейтов и матрица матчапов
├── users_db.py             # SQLite база для личных токенов пользователей
├── aliases.py              # Русские прозвища и сленг героев Dota 2
├── deploy.sh / update.sh   # Автодеплой и быстрое обновление на Ubuntu VPS
├── run.bat / setup.bat     # Быстрый запуск и установщик для Windows
├── templates/index.html    # Разметка интерфейса
├── static/css/style.css    # Стилистика (Dark Glassmorphism, Segoe UI)
├── static/js/app.js        # Реактивное состояние, фокус слотов, драфт-метр, popover
└── data/                   # Локальный оффлайн-кэш (heroes, stats, matchups)
```
