# StratzDrafter — Инструкции и Архитектура Проекта (GEMINI.md)

Этот файл содержит всю ключевую информацию об архитектуре, алгоритмах, структуре данных и UI/UX решениях проекта **StratzDrafter**, чтобы не приходилось повторно анализировать базу при каждом запросе.

---

## 1. Описание Проекта
**StratzDrafter** — локальное веб-приложение для драфта в Dota 2 на базе **Stratz GraphQL API**.
* **Основная концепция:** Фокус на контрпиках (по умолчанию 70%), синергии связок команды (20%) и силе героев в мете (10%).
* **Режим драфта для пати:** Сетка 5 колонок (Поз 1 — Керри, Поз 2 — Мид, Поз 3 — Оффлейн, Поз 4 — Семи-саппорт, Поз 5 — Фулл-саппорт), позволяющая сразу советовать пики друзьям.
* **Локальный кэш:** Для мгновенного отклика все данные (герои, статистика ролей и матрица матчапов 127x127) кэшируются на диске в формате JSON.

## 3. Архитектура и Ключевые Алгоритмы

### 3.1. Клиент Stratz (`stratz_client.py`)
1. **Кэширование на диск:**
   * Метод `_load_disk_cache()` загружает `heroes_cache.json`, `stats_cache.json`, `matchups_cache.json`.
   * При старте фоновый поток `preload_all_matchups_async()` проверяет и догружает недостающие матчапы пачками по 25 героев.
2. **Фильтрация ролей (`is_hero_viable_for_position`):**
   * Стандартный пик: доля игр на роли $\ge 15\%$ или $\ge 2000$ игр.
   * Офф-мета: доля игр $\ge 4\%$ и $\ge 150$ игр (переключатель `allowOffMeta` в UI).
3. **Рекомендации (`calculate_recommendations` & `get_team_recommendations_matrix`):**
   * Уже пикнутые союзники, враги и забаненные герои строго исключаются (`taken_heroes`).
   * Взвешенный скор:
     $$\text{totalScore} = w_c \cdot \text{Counter} + w_s \cdot \text{Synergy} + w_m \cdot \text{Meta}$$
4. **Расчет Шанса Победы (`calculate_draft_analysis`):**
   * **ВАЖНО:** Нельзя пытаться искать пикнутых героев в `matrix.pos1..pos5`, так как они оттуда исключены!
   * Расчет производится на бэкенде:
     * **Контрпики:** Попарное сравнение союзников и врагов через `matchups[a]['vs'][e]['synergy']`. Находятся `bestCounters` (лучшие контрпики союзников) и `biggestThreats` (опасные контрпики врагов).
     * **Синергия:** Оценка связок внутри союзной команды и внутри вражеской команды через матрицу `with`.
     * **Мета:** Базовый винрейт героев в патче (с учетом роли из `position_stats`).
     * **Итог:** Шанс победы союзников нормируется в диапазоне от 15.0% до 85.0%, врагов — $100 - \text{AlliesWinRate}$.
     * **Подсказка (`insight`):** Генерирует читаемое описание на русском языке о ключевых контрпиках или угрозах драфта.

### 3.2. Бэкенд эндпоинты (`app.py`)
* `GET /api/heroes?q=...&attr=...` — Список всех героев с поддержкой поиска по русскому сленгу.
* `POST /api/recommend` — Топ-50 рекомендаций для конкретной позиции или всех ролей + анализ драфта.
* `POST /api/team_matrix` — Матрица рекомендаций для всех 5 позиций одновременно + `analysis` шанса победы.
* `POST /api/draft_analysis` — Быстрый прямой расчет шанса победы и инсайтов драфта.
* `GET /api/status` — Статус кэша, токена и фонового предзагрузчика.
* `POST /api/preload` — Запуск фонового прогрева кэша.

### 3.3. Клиентская часть (`static/js/app.js`)
* Хранит состояние драфта: `state.allies` (5 слотов), `state.enemies` (5 слотов), `state.bans`.
* `debouncedUpdate()` (задержка 200 мс) вызывает `triggerUpdate()`, который отправляет `allies`, `enemies`, `alliesRoles`, `bans`, `weights`, `bracket` на сервер.
* Функция `updateDraftMeter(analysis)` обновляет полосу, подписи (`X.X% Наша` / `X.X% Враг`) и текст `draftInsight`.
* Поиск героев в модалке поддерживает русский сленг из `aliases.py` (например: «фура», «ам», «гуля», «папич», «пудж»).
* Клик по слоту открывает модалку; ЛКМ — выбор героя, ПКМ — отправка героя в бан.

## 4. UI / UX и Стилистические Соглашения

1. **Типографика:**
   * Основной шрифт для заголовков, бейджей, кнопок и процентов — **`Segoe UI`, sans-serif** (пользователь предпочитает `Segoe UI` вместо `Rajdhani`).
2. **Секция WINRATE над VS:**
   * Над бейджем `VS` расположен элемент `.meter-winrate-title` с текстом **WINRATE**.
   * Текст белый (`#ffffff`), с крупным кеглем и глоу-эффектом.
   * Бейдж `VS` золотистый (`#f6c445`) с золотым свечением.
3. **Шапка (Header):**
   * Логотип Доты **удален** по требованию пользователя. Отображается только текстовый заголовок `STRATZ DRAFTER`.
4. **Контакты (Footer):**
   * В самом низу страницы расположен футер `.app-footer` со ссылками:
     * Telegram: `@noootle` (`https://t.me/noootle`)
     * GitHub: `https://github.com/smeshar/StratzDrafter`
   * Оформлен в виде pill-кнопок с подсветкой при наведении.

## 5. Запуск и Эксплуатация
* **Команда запуска:** `python app.py` (или через `run.bat`).
* **Адрес:** `http://127.0.0.1:5000`
* **Окружение:** `.env` файл с переменной `STRATZ_API`. Если токен отсутствует, приложение работает на оффлайн-кэше из папки `data/`.

```
├── test_stratz_client.py # 8 тестов: загрузка кэша, фильтрация ролей, расчет контрпиков, скор формулы, матрица 5 позиций
├── test_api.py           # 14 тестов: эндпоинты Flask (/api/heroes, /api/recommend, /api/team_matrix, /api/draft_analysis, /api/status)
└── test_e2e_browser.py   # 7 E2E тестов в Chromium (Playwright): клики по слотам, модалка, поиск, драфт-метр, баны, сброс
```

### Запуск тестов:
* **В 1 клик на Windows:** запустить [run_tests.bat](file:///d:/VSCodeProjects/StratzDrafter/run_tests.bat) (интерактивное меню выбора тестов).
* **Все тесты:** `pytest`
* **Только быстрые Unit & API тесты (< 1 сек):** `pytest -m "unit or api"`
* **Только E2E браузерные тесты:** `pytest tests/test_e2e_browser.py`
* **E2E тесты с показом окна браузера:** `pytest tests/test_e2e_browser.py --headed`
