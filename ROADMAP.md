# Roadmap & Идеи — StratzDrafter

## Идеи
- [ ] История драфтов (сохранение пиков прошлых матчей)
- [ ] Профиль игрока: учет сигнатурных героев каждого из друзей пати
- [ ] Тренировочный полигон для анализа как хорошо ты умеешь драфтить
- [ ] Если фокус на какой-то позиции, то если я начну вписывать название героя то откроется список героев и я смогу выбрать
- [ ] Список выбора героев сделать сильно поменьше и чтоб он вылезал как бы под стрелочкой когда начинаешь набирать название героя а не на весь экран
- [ ] Оценка пика каждого героя (как хорошо он взял для врагов тоже)
- [ ] Сверху под настройками сделать график ожидаемого преимущества с 0 минуты до 60
- [ ] Справа Stratz Drafter в овальчике написать BETA (на голубом фоне овальчика)
- [ ] Справа названия сделать номер патча желтым цветом (например: 7.41f)
- [ ] Ранг матча чтоб можно было выбирать по иконкам рангов (а не по названиям)
