# Roadmap & Идеи — StratzDrafter

## Идеи
- [ ] История драфтов (сохранение пиков прошлых матчей)
- [ ] Профиль игрока: учет сигнатурных героев каждого из друзей пати
- [ ] Оценка пика каждого героя (как хорошо он взял для врагов тоже по 100 бальной шкале вот получается вместо штуки WINRATE убрать винрейт команд и там сделать вот 5 прямоугольников для союзников где по 100 бальной шкале будет оценка пика и для врагов тоже а еще вот снизу под выборами будет таблица для каждого героя его синергия с остальными тиммейтами и контрпик каждого врага по отдельности)
- [ ] Сверху под настройками сделать график ожидаемого преимущества с 0 минуты до 60
- [ ] Справа Stratz Drafter в овальчике написать BETA (на голубом фоне овальчика)
- [ ] Справа названия сделать номер патча желтым цветом (например: 7.41f)
